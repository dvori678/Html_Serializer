# Html Serializer

פרויקט במסגרת קורס **פרקטיקוד**.

כלי ב-C# לניתוח דפי HTML וחיפוש אלמנטים בהם לפי CSS Selector.
הכלי מהווה תשתית לבניית Crawler - מנגנון שקורא דפי אינטרנט ומחלץ מהם מידע.

## חלקי הפרויקט

### Html Serializer
- טעינת דף אינטרנט באמצעות `HttpClient`
- פירוק ה-HTML לתגיות באמצעות Regular Expressions
- בניית עץ של אובייקטי `HtmlElement` בלולאה (ללא רקורסיה, למניעת Stack Overflow)
- זיהוי תגיות שסוגרות את עצמן, מאפיינים, id ו-classes

### Html Query
- המרת מחרוזת שאילתה לשרשרת של אובייקטי `Selector`
- חיפוש רקורסיבי בעץ לפי הסלקטור
- מניעת כפילויות בתוצאות באמצעות `HashSet`

## סלקטורים נתמכים

| סלקטור | משמעות |
|---|---|
| `div` | לפי שם תגית |
| `#my-id` | לפי id |
| `.my-class` | לפי class |
| `div#my-id.my-class` | אלמנט שעונה על כל התנאים |
| `div .my-class a` | חיפוש בצאצאים (לעומק) |

## מבנה הפרויקט

- `HtmlElement` - מייצג תגית HTML, כולל `Descendants()` ו-`Ancestors()`
- `HtmlHelper` - Singleton שטוען את רשימות התגיות מקבצי JSON
- `Selector` - מייצג סלקטור והמרה ממחרוזת
- `HtmlElementExtensions` - פונקציית הרחבה לחיפוש אלמנטים בעץ
